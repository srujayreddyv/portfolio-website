- Built a Python MCP platform that gives AI agents read-only repository inspection across files, directories, text search, documentation, and Git history.

- Implemented 9 tools: `read_file`, `list_directory`, `search_files`, `git_log`, `git_diff`, `git_status`, `git_branches`, `grep_search`, and `docs_search`.

- Architected an extensible tool registry with JSON Schema validation and dynamic capability discovery so new agent tools can be registered without changing core request routing.

- Added path containment checks, execution tracing, an interactive CLI client, and a local browser dashboard to make repository inspection safer and easier to test.

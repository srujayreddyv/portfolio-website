- Created a lightweight repository memory standard for AI coding agents, preserving durable codebase knowledge that source code alone does not explain: architectural boundaries, engineering decisions, repository conventions, and long-term constraints.

- Designed a small, repository-centric structure with `AGENTS.md`, `memory/CODEBASE.md`, `memory/ARCHITECTURE.md`, `memory/PATTERNS.md`, `memory/DECISIONS.md`, and reusable task planning and review templates.

- Established a practical workflow for AI-assisted engineering: read memory, create a task plan, implement minimal changes, verify results, review risks, and update memory only when durable repository knowledge changes.
